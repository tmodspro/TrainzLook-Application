# TrainzLook — landing page

Situs statis Next.js untuk TrainzLook (gratis, publisher INDORAILS). Aplikasi desktopnya ada di repo TrainzLook terpisah; rancangan situs ini di `docs/03-landing-page.md` repo tersebut.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # hasil statis di out/
```

Semua fakta di halaman (versi, URL unduhan, ukuran, SHA-256, daftar fitur, FAQ) ada di `src/site.ts`.
